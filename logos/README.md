# Provider logos

Original provider branding used to identify the current webcam source in the popup.
These files are bundled by the frontend and served from this application's own assets;
opening a popup does not download a logo from a third-party site.

| Provider | Local file | Official source |
| --- | --- | --- |
| Windy | `windy.png` | [Windy icon](https://img.windy.com/albums/icons/logo-full.png?w=180), linked from [Windy](https://www.windy.com/) |
| Skaping | `skaping.png` | [Skaping logo](https://about.skaping.com/wp-content/uploads/2015/12/skaping-copie.png), identified in the organization's [official website](https://about.skaping.com/) metadata |
| Fintraffic | `fintraffic.svg` | The `logo` symbol in the [official SVG sprite](https://www.fintraffic.fi/themes/custom/traffic/dist/sprites/graphics.svg?v1.0.1), used in the [Fintraffic](https://www.fintraffic.fi/en) header |
| Météo Centre | `meteo-centre.png` | [Météo Centre logo](https://www.meteo-centre.fr/wp-content/uploads/logo200x200-1.png), displayed on [Météo Centre](https://www.meteo-centre.fr/) |

Retrieved 2026-11-26. PNGs are unchanged. Fintraffic's original logo paths and viewBox
are extracted into a standalone SVG; other symbols from its sprite are omitted.
The logos and names remain the property of their respective providers.
